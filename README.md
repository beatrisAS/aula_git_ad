## 🎯 Sobre este repositório

Este repositório foi criado durante o **Bootcamp de Analista de Dados da Generation Brasil** para praticar os fundamentos de **versionamento com Git e GitHub**.

A ideia é aprender a acompanhar alterações nos arquivos, registrar mudanças em commits e enviar o histórico do projeto para um repositório remoto.

## 🛠️ O que estou praticando

- Verificar o estado dos arquivos com `git status`;
- Preparar alterações para um commit com `git add`;
- Registrar alterações com `git commit`;
- Consultar o histórico usando `git log`;
- Desfazer uma alteração registrada com `git revert`;
- Configurar um repositório remoto com `git remote`;
- Enviar commits ao GitHub com `git push`.

## 📁 Arquivo de prática

- `Turma.py` — arquivo utilizado nos exercícios de alteração e versionamento.

## 💻 Comandos usados

```bash
# Conferir o estado do repositório
git status

# Preparar alterações
git add .

# Criar um commit
git commit -m "Descreve a alteração"

# Consultar o histórico de commits
git log --oneline

# Enviar a branch main para o GitHub
git push origin main
```

## 📚 Objetivo de aprendizagem

Familiarizar-me com o fluxo básico de versionamento e entender como o Git registra as mudanças feitas ao longo do desenvolvimento.
