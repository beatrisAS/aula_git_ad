## 🎯 Sobre este repositório

Este projeto foi criado durante o **Bootcamp de Analista de Dados da Generation Brasil**. O objetivo principal é consolidar os conhecimentos adquiridos na semana, unindo a base de **versionamento de código com Git/GitHub** com os **fundamentos de lógica de programação em Python**. 

## 📚 Assuntos da Semana

Durante os estudos recentes, o foco foi construir a base técnica necessária para a área de dados. Os principais temas abordados foram:

**1. Fundamentos de Python**
- **Variáveis:** Como armazenar dados na memória (textos, números, etc).
- **Entrada e Saída (I/O):** Interação com o código utilizando `input()` para receber dados e `print()` para exibir resultados.
- **Estruturas de Dados (Listas):** Agrupamento de vários valores em uma única variável, entendendo a contagem a partir do índice zero (0).
- **Manipulação de Listas:** Uso de métodos como `.append()` (adicionar), `.remove()` e `.pop()` (remover itens).

**2. Versionamento com Git e GitHub**
- Ciclo de vida dos arquivos (untracked, modified, staged).
- Criação de histórico de alterações seguro com commits.
- Conexão entre repositório local (na máquina) e remoto (na nuvem).

**3. Base Analítica e Profissional**
- Introdução ao ecossistema de dados.
- Preparação lógica para os próximos passos em bancos de dados relacionais e SQL.
- Desenvolvimento de competências comportamentais para o mercado de tecnologia.

## 🛠️ Comandos de Git Praticados

**🔄 No Repositório Local (Terminal):**
- `git status`: Verificar o estado e o rastreamento dos arquivos.
- `git add .`: Adicionar todas as alterações na área de preparação.
- `git commit -m "mensagem"`: Registrar as mudanças com descrições claras.
- `git log --oneline`: Consultar o histórico de commits de forma resumida.
- `git revert`: Desfazer alterações registradas.

**☁️ No Repositório Remoto (GitHub):**
- `git remote`: Configurar a conexão com o repositório na nuvem.
- `git push origin main`: Enviar as atualizações para o GitHub.
